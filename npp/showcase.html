9. Quick N++ Reference

N++ Code What it does
set page to webpage("Title", "dark") Create a webpage with dark theme
navbar("Brand", links, "CTA", "/url") Full navigation bar with links
hero("Big Title", "Subtitle", "Btn", "#") Full-width hero section
set c to card("Title", "Desc", "🚀") Create a feature card
page.add(grid(3, [c1, c2, c3])) 3-column responsive card grid
export_html("index.html", page) Save the rendered HTML file
say "Hello World" Print output to terminal
set x to 42 Declare a variable
